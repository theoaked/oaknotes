# Bem-vindo ao OakNotes 🌳

Esta página lista **todos os arquivos `.md`** dentro da pasta `notes/` deste
repositório e permite navegar, ler e baixar cada um.

## Como funciona

- A **navegação** à esquerda reflete a estrutura de pastas dentro de `notes/`.
- A **busca** no topo filtra por nome; ative **"no conteúdo"** para procurar
  dentro dos arquivos.
- O botão **Baixar** salva o `.md` original no seu computador.
- O **sumário** à direita lista os cabeçalhos do documento aberto.

## Recursos de Markdown suportados

Tabelas, listas de tarefas, código com realce, diagramas Mermaid e muito mais.

| Recurso        | Suportado |
| -------------- | :-------: |
| GFM (tabelas)  |     ✅     |
| Tarefas        |     ✅     |
| Realce de código |   ✅     |
| Mermaid        |     ✅     |
